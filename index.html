🐾 Đồng bộ GitHub

Đẩy trực tiếp lên GitHub thay vì phải tải JSON rồi tự tay upload — repo tự động của bạn sẽ nhận file mới và gửi qua Telegram như bình thường. Chỉ hoạt động khi mở file .html tải về trên máy (không hoạt động ở link app xem trước, do trình duyệt chặn gọi API từ trang xem trước).

Token cần quyền repo (hoặc Contents: Read and write nếu là fine-grained token) và chỉ lưu trong trình duyệt của bạn (localStorage) — không gửi cho ai khác ngoài GitHub. App sẽ tự tạo file nếu chưa có, hoặc cập nhật đè lên nếu đã tồn tại.

Mỗi lần nhập file Excel sẽ tạo một bộ từ vựng mới (không ghi đè bộ đang có) — chọn bộ cần học ở góc trên bên phải hoặc trong bảng bên trên. Các dòng trùng nhau (cùng chữ Hán + cùng pinyin) sẽ tự động bị loại bỏ khi nhập.
Danh sách giọng đọc gồm giọng online của Google Chrome (cần Chrome + mạng) và giọng cài sẵn trên máy (dùng được cả khi mất mạng) — có cả giọng nam lẫn giọng nữ nếu máy bạn có. App đọc sheet shengci (nếu không có sẽ lấy sheet đầu tiên). Thứ tự cột như file gốc: A từ vựng · B pinyin · C từ loại · D nghĩa tiếng Việt · E cách dùng · F ví dụ · G pinyin ví dụ · H dịch ví dụ · I từ trái nghĩa · J nhóm. Cột J (nhóm) được ưu tiên dùng để chọn 3 đáp án nhiễu cùng nhóm; nếu một nhóm không có đủ từ để chọn, hệ thống tự dùng các từ có cùng số chữ Hán để luôn đảm bảo đủ đáp án nhiễu hợp lý. Dữ liệu chỉ lưu trong trình duyệt của bạn (localStorage) — đổi máy hoặc xoá cache sẽ mất dữ liệu.
